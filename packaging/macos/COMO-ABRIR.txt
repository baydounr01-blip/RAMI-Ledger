RAMI-Chain en macOS — LÉEME ANTES DE ABRIR
============================================

ESTADO: esta build aún NO está firmada ni notarizada por Apple, así que macOS
mostrará el aviso «Apple no pudo verificar que no contenga software malicioso»
y NO pasa todavía el filtro de malware de Apple.

▶ SI NO ERES UN USUARIO TÉCNICO: no la instales aún. Espera a la versión
  FIRMADA Y NOTARIZADA (sin ningún aviso). Nunca te pediremos que te saltes un
  aviso de seguridad: esos avisos existen para protegerte.

▶ SOLO USUARIOS AVANZADOS — si decides abrirla, en este orden:

  1) VERIFICA SIEMPRE PRIMERO. Comprueba que el SHA-256 de tu descarga coincide
     con el SHA256SUMS.txt del release oficial:
        shasum -a 256 <archivo.dmg>
     Si no coincide, bórrala. No abras nada que no hayas verificado.

  2) Abre de forma consciente (método soportado por Apple):
     clic derecho sobre RAMI-Chain → Abrir → Abrir. Si no aparece la opción:
     Ajustes del Sistema → Privacidad y seguridad → «Abrir de todas formas».
     Al hacerlo, la verificación que normalmente haría Apple la asumes tú
     (por eso el paso 1 no es opcional).

La versión firmada y notarizada se publicará con los certificados Developer ID
del proyecto; el sistema de publicación ya está preparado (ver SIGNING.md).

¿LA APP NO ABRE (ni siquiera la primera vez)?
1) Comprueba el CHIP: menú  → «Acerca de este Mac». Chip Apple M1/M2/M3/M4 =
   descarga «Apple Silicon»; Intel = descarga «Intel». Con el .dmg equivocado
   la app no puede abrir.
2) Arrastra la app a APLICACIONES antes de abrirla (no la ejecutes desde la
   ventana del .dmg).
3) Mira si existe el archivo ~/.rami/gui-launch.log (Finder → Ir → Ir a la
   carpeta… → escribe ~/.rami). Si NO existe, macOS nunca llegó a ejecutar la
   app (chip equivocado o bloqueo del sistema). Si existe, dentro está el
   motivo del fallo — envíanoslo para ayudarte.
4) Desde Terminal puedes ver el error en directo:
   /Applications/RAMI-Chain.app/Contents/MacOS/rami-gui

CÓMO SE USA LA APP
El monedero vive en tu navegador (panel local en http://127.0.0.1:8645).
  • Doble clic en la app: arranca el nodo y abre el panel.
  • Si el panel ya está abierto y vuelves a hacer clic en el icono, se vuelve
    a abrir el panel en el navegador (desde v0.5.1; antes macOS podía decir
    «no responde» — el nodo funcionaba, pero la app no atendía al clic).
  • Para cerrarla del todo: botón «⏻ Salir» del panel (arriba a la derecha).
  • Si algún día ves «no responde»: abre http://127.0.0.1:8645 — el nodo sigue
    funcionando — y actualiza a la última versión desde la pestaña Actualizar.
  • ACTUALIZAR (desde v0.5.2): pestaña «Actualizar» → «Actualizar ahora». La app
    descarga el .dmg oficial, comprueba su SHA-256, instala la versión nueva
    encima de la actual, se cierra y se vuelve a abrir sola; el panel se
    recarga. No hay que arrastrar nada. Si algo falla, se abre el .dmg
    verificado para hacerlo a mano y el motivo queda en ~/.rami/gui-launch.log.

RAMI-Chain on macOS — README FIRST (English)

STATUS: this build is NOT yet signed or notarized by Apple, so macOS will show
"Apple could not verify it is free of malware" and it does NOT yet pass Apple's
malware check.

▶ IF YOU ARE NOT A TECHNICAL USER: do not install it yet. Wait for the SIGNED
  AND NOTARIZED release (no warning at all). We will never ask you to bypass a
  security warning.

▶ ADVANCED USERS ONLY — if you choose to open it, in this order:
  1) ALWAYS VERIFY FIRST: `shasum -a 256 <file.dmg>` must match the official
     release's SHA256SUMS.txt. If it doesn't, delete it.
  2) Open deliberately (Apple-supported method): right-click → Open → Open, or
     System Settings → Privacy & Security → "Open Anyway". You are taking on
     the verification Apple would normally do (which is why step 1 is mandatory).

APP "NOT RESPONDING" WHEN YOU REOPEN IT?
The wallet lives in your browser (local dashboard). If you close the tab, the
app keeps running in the background and macOS won't relaunch it on click.
  • To get back to the dashboard: open http://127.0.0.1:8645 in your browser.
  • To quit completely: use the "⏻ Salir" (Quit) button in the dashboard's top
    bar. After that, the icon opens the app normally again.

The signed/notarized release ships once the project's Developer ID certificates
are in place (see SIGNING.md). Experimental testnet, no monetary value.
